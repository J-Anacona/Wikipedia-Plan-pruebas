## 2. Objetivo

Verificar que el buscador de Wikipedia en español permita encontrar artículos mediante diferentes tipos de consultas y gestione adecuadamente las búsquedas sin resultados.

## 3. Precondiciones

- Tener conexión a Internet y un navegador actualizado.
- Acceder a https://es.wikipedia.org/.
- No tener iniciada una sesión de usuario.

## 4. Datos de prueba y resultados esperados

| Escenario | Dato de entrada | Resultado esperado |
|---|---|---|
| Búsqueda exacta | Colombia | Acceder al artículo correspondiente. |
| Búsqueda parcial | Colom | Mostrar resultados relacionados con el término. |
| Redirección | Colombia (república) | Dirigir al artículo de destino Colombia. |
| Error tipográfico | Colomiba | Procesar la consulta y mostrar resultados o sugerencias relacionadas, si existen. |
| Sin resultados | zzzxqvprueba987654 | Informar que no se encontraron resultados relevantes. |

## 5. Pasos de ejecución

Para cada escenario:

1. Abrir Wikipedia en español.
2. Introducir el dato correspondiente en el buscador.
3. Presionar Enter.
4. Observar y comparar el resultado con el esperado.
5. Guardar una captura de pantalla como evidencia.

## 6. Criterios de aceptación

El caso se aprobará si los cinco escenarios cumplen sus resultados esperados, sin errores inesperados de búsqueda o navegación.

Cada escenario se calificará individualmente como Aprobado o Fallido.

## 7. Registro de resultados

| Escenario | Resultado obtenido | Estado |
|---|---|---|
| Búsqueda exacta | Se accedió correctamente al artículo de Colombia. | Aprobado |
