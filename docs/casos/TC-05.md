## 2. Objetivo

Verificar que la página aleatoria, los enlaces internos y las anclas del índice de un artículo lleven al destino correcto.

## 3. Precondiciones

- Tener conexión a Internet y un navegador actualizado.
- Acceder a https://es.wikipedia.org/.
- No tener iniciada una sesión de usuario.

## 4. Datos de prueba y resultados esperados

| Escenario | Dato de entrada | Resultado esperado |
|---|---|---|
| Página aleatoria | Opción "Página aleatoria" del menú, usada 3 veces | Cada vez se abre un artículo existente, con título y contenido, sin error. |
| Enlace interno | Un enlace del texto de un artículo (por ejemplo, [enlace elegido]) | Se abre el artículo que nombra el enlace. |
| Ancla del índice | Una sección del índice de un artículo largo ([artículo y sección]) | La página se desplaza hasta la sección elegida, con el mismo título. |

## 5. Pasos de ejecución

Para cada escenario:

1. Abrir Wikipedia en español.
2. Realizar la acción del dato de entrada (usar la página aleatoria, pulsar el enlace o pulsar la sección del índice).
3. Observar el destino y compararlo con el esperado.
4. Anotar el título del destino y el enlace permanente (oldid) del artículo.
5. Guardar una captura de pantalla como evidencia.

## 6. Criterios de aceptación

El caso se aprobará si los tres escenarios cumplen su resultado esperado, sin errores de navegación.

Cada escenario se calificará individualmente como Aprobado o Fallido.
