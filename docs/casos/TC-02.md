# TC-02 – Cambio y persistencia de la apariencia

## 1. Identificación

| Campo | Descripción |
|---|---|
| Identificador | TC-02 |
| Nombre | Cambio del tamaño de texto, anchura y color del menú de apariencia, y verificación al navegar a otra página |
| Elemento de prueba | EP-02 – Apariencia |
| Condición de prueba | CP-02 – Persistencia de la apariencia |
| Riesgo asociado | RSK-03 – Los ajustes de texto, anchura o color no se aplican o no se conservan al navegar |
| Prioridad | 1 – Alta |
| Tipo de prueba | Manual |
| Técnica | Transición de estados |

## 2. Objetivo

Comprobar que las opciones de apariencia de Wikipedia en español permitan modificar correctamente el tamaño del texto, la anchura de la página y el color de visualización. También se verificará que cada configuración seleccionada se conserve al navegar desde un artículo hacia otro.

## 3. Alcance

Se probarán las siguientes opciones del menú Apariencia:

- **Texto:** Pequeño, Estándar y Grande.
- **Anchura:** Estándar y Ancho.
- **Color (beta):** Automático, Claro y Oscuro.

La prueba se realizará en la interfaz de Wikipedia en español, sin iniciar sesión y sin modificar el contenido de los artículos.

## 4. Precondiciones

1. Tener conexión a Internet.
2. Abrir el navegador Google Chrome o Microsoft Edge.
3. Acceder a https://es.wikipedia.org.
4. No tener una sesión iniciada en Wikipedia.
5. Abrir un artículo de Wikipedia, por ejemplo, Colombia.
6. Tener visible el menú Apariencia.

## 5. Datos de prueba

| Configuración | Valores que se probarán |
|---|---|
| Texto | Pequeño, Estándar, Grande |
| Anchura | Estándar, Ancho |
| Color (beta) | Automático, Claro, Oscuro |
| Artículo inicial | Colombia |
| Artículo de navegación | Medellín |

## 6. Procedimiento de prueba

### Escenario 1: Cambio y persistencia del tamaño del texto

1. Abrir el artículo Colombia.
2. Expandir el menú Apariencia.
3. En la sección Texto, seleccionar Pequeño.
4. Verificar que el tamaño del texto cambie.
5. Navegar al artículo Medellín.
6. Verificar que el tamaño Pequeño se conserve.
7. Repetir el procedimiento con las opciones Estándar y Grande.
8. Registrar los resultados obtenidos.

### Escenario 2: Cambio y persistencia de la anchura

1. Abrir el artículo Colombia.
2. Expandir el menú Apariencia.
3. En la sección Anchura, seleccionar Estándar.
4. Verificar que la anchura de la página corresponda a la opción seleccionada.
5. Navegar al artículo Medellín.
6. Verificar que la configuración Estándar se conserve.
7. Repetir el procedimiento con la opción Ancho.
8. Registrar los resultados obtenidos.

### Escenario 3: Cambio y persistencia del color

1. Abrir el artículo Colombia.
2. Expandir el menú Apariencia.
3. En la sección Color (beta), seleccionar Automático.
4. Verificar que se aplique el modo de color correspondiente.
5. Navegar al artículo Medellín.
6. Verificar que la configuración Automático se conserve.
7. Repetir el procedimiento con las opciones Claro y Oscuro.
8. Registrar los resultados obtenidos.

## 7. Resultados esperados

- Cada opción de Texto debe modificar el tamaño de los caracteres de acuerdo con la selección.
- Cada opción de Anchura debe modificar la presentación horizontal del contenido.
- Cada opción de Color debe aplicar el modo de visualización correspondiente.
- Al navegar a otro artículo, la configuración seleccionada debe mantenerse.
- Las opciones deben poder cambiarse sin generar errores en la interfaz.

## 8. Criterios de aprobación

Un escenario se considera aprobado cuando:

1. La opción seleccionada se aplica correctamente.
2. El cambio visual corresponde a la configuración elegida.
3. La configuración se conserva después de navegar a otro artículo.

Si alguna opción no se aplica o no se conserva, se registrará el resultado como Fallido y se documentará la evidencia correspondiente.
