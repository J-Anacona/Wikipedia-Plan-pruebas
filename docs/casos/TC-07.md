## 2. Objetivo

Comprobar que un artículo corto, uno mediano y uno muy largo carguen dentro del tiempo aceptable definido, sin deteriorar el uso.

## 3. Precondiciones

- Tener conexión a Internet y un navegador actualizado, sin extensiones.
- Abrir las herramientas de desarrollo (pestaña Network) con la caché desactivada.
- No tener iniciada una sesión de usuario.
- Tener definido el umbral de tiempo aceptable: [X segundos] (se fija antes de medir).

## 4. Datos de prueba y resultados esperados

| Escenario | Dato de entrada | Resultado esperado |
|---|---|---|
| Artículo corto | [artículo corto elegido] | Carga en un tiempo menor o igual al umbral. |
| Artículo mediano | [artículo mediano elegido] | Carga en un tiempo menor o igual al umbral. |
| Artículo muy largo | [artículo muy largo elegido] | Carga en un tiempo menor o igual al umbral. |

De cada artículo se anotan el enlace permanente (oldid) y la fecha.

## 5. Pasos de ejecución

Para cada artículo:

1. Abrir las herramientas de desarrollo en la pestaña Network, con la caché desactivada.
2. Cargar el artículo.
3. Anotar el tiempo de carga que muestra la pestaña Network.
4. Repetir la medición 3 veces.
5. Anotar fecha, hora y tipo de conexión.
6. Guardar una captura de pantalla de la pestaña Network como evidencia.

## 6. Criterios de aceptación

El caso se aprobará si, en cada artículo, el promedio de las 3 mediciones es menor o igual al umbral definido.

Cada artículo se calificará individualmente como Aprobado o Fallido.
