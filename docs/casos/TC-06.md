## 2. Objetivo

Verificar que el formulario de inicio de sesión rechace los datos inválidos con mensajes claros, sin revelar información de cuentas y sin permitir el acceso.

## 3. Precondiciones

- Tener conexión a Internet y un navegador actualizado.
- Acceder a la página de inicio de sesión de https://es.wikipedia.org/.
- No tener iniciada una sesión de usuario.
- Usar solo credenciales ficticias: no crear cuentas, no usar contraseñas reales ni cuentas de otras personas.

## 4. Datos de prueba y resultados esperados

| Escenario | Dato de entrada | Resultado esperado |
|---|---|---|
| Campos vacíos | Usuario vacío y clave vacía | No se permite el acceso; se muestra un aviso de campo obligatorio o de error. |
| Clave vacía | Usuario ficticio y clave vacía | No se permite el acceso; se muestra un aviso claro. |
| Usuario inexistente | Usuario ficticio y clave ficticia | No se permite el acceso; el mensaje de error es claro y no revela si el usuario existe. |
| Valor límite inferior | Usuario de 1 carácter y clave de 1 carácter | No se permite el acceso; el formulario responde sin fallar. |

## 5. Pasos de ejecución

Para cada escenario:

1. Abrir la página de inicio de sesión de Wikipedia en español.
2. Introducir los datos del escenario.
3. Pulsar el botón de iniciar sesión.
4. Observar el mensaje y comparar con el resultado esperado.
5. Guardar una captura de pantalla como evidencia.

Se hacen pocos intentos, solo los de la tabla, para no activar bloqueos.

## 6. Criterios de aceptación

El caso se aprobará si los cuatro escenarios rechazan el acceso con mensajes claros y sin revelar información sobre las cuentas.

Cada escenario se calificará individualmente como Aprobado o Fallido.
